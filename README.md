# Multilingual OCR Tool (Hindi + English)

This is a simple Web-based OCR tool built with Streamlit and EasyOCR that can extract text from images in Hindi, English, and Hinglish.

## Features
- Upload JPG/PNG images.
- High accuracy for Devanagari and Latin scripts.
- Download extracted text as a .txt file.

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
